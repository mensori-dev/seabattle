# Сборка для Яндекс Игр

Отдельная версия «Морского боя» для платформы [Яндекс Игры](https://games.yandex.ru/console):
одиночная игра против бота без онлайна, с рекламой через SDK платформы.

Исходники те же, что и у основной игры. Сборка ничего не форкает и не дублирует:
`scripts/build-yandex.mjs` копирует нужные файлы и вырезает всё, что платформа
запрещает или не поддерживает.

## Сборка

```bash
npm run yandex            # dist/yandex + dist/seabattle-yandex-<версия>.zip
npm run yandex -- --no-zip  # только папка (так делает npm test)
```

Что получается:

- `index.html` в корне архива — обязательное требование платформы;
- без онлайна: `js/online.js` не копируется, `js/yandex.js` подставляет заглушку
  `window.Online`, чтобы общий `app.js` не падал;
- без Google Fonts: Nunito и Rubik лежат в `assets/fonts` (OFL 1.1);
- без PWA: manifest, `sw.js`, apple-иконки и подсказка «добавь на iPhone» вырезаны;
- без внешних ссылок: политика конфиденциальности и витрина сайта не попадают в архив;
- подключён `/sdk.js` и `js/yandex.js`: `LoadingAPI.ready()`, `GameplayAPI`,
  пауза по `game_api_pause`, полноэкранная реклама между боями и rewarded-бонус.

Имена файлов без пробелов и кириллицы, распакованный размер — около 300 КБ.
Тест `tests/yandex-build.test.mjs` собирает версию и проверяет эти правила.

## Что делает `js/yandex.js`

| Возможность | Где вызывается |
|---|---|
| `LoadingAPI.ready()` | конец инициализации, меню показано |
| `GameplayAPI.start/stop` | `beginBattle()` / `endGame()` |
| `game_api_pause` / `game_api_resume` | глушим звук, останавливаем бота, блокируем выстрелы |
| `showFullscreenAdv()` | кнопка «Ещё бой», но не раньше третьего боя и не чаще раза в 90 секунд |
| `showRewardedVideo()` | кнопка «🎁 Бонус за рекламу» на экране результата: +25 к рейтингу, раз в день |

Частота межстраничной рекламы хранится в профиле (`adMatches`, `lastAdAt`),
дата rewarded-бонуса — в `adBonusDate`. Ключ профиля `seabattle.profile.v2` не менялся:
новые поля добавляются с значениями по умолчанию.

## Локальная проверка без платформы

В обычной сборке `window.YandexGame` нет, и все хуки пропускаются. Чтобы проверить
рекламу и паузу, положите рядом с собранной папкой заглушку `sdk.js`
(`window.YaGames = { init: () => Promise.resolve({...}) }`) и откройте сборку по HTTP.
Так проверены: `ready`, старт и стоп геймплея, блокировка выстрелов на паузе,
rewarded-бонус и межстраничная реклама.

Шрифты перегенерируются командой `npm run fonts` (нужен интернет).

## Требования модерации: чек-лист

- [x] SDK подключён до `YaGames.init()`, лоадер в debug-панели показывает `IT`.
- [x] `LoadingAPI.ready()` вызывается, когда меню готово к нажатиям.
- [x] Звук и игровой процесс останавливаются на `game_api_pause`.
- [x] Реклама только через SDK и только в логических паузах (экран результата).
- [x] Нет внешних ссылок, сторонней авторизации и сторонних скриптов.
- [x] Прогресс гостя хранится в `localStorage` и не теряется между сессиями.
- [ ] Язык: интерфейс только русский — в карточке игры указать русский язык.
- [ ] Возрастной рейтинг: без крови и азартных механик, подходит для 6+.
- [ ] Промо: иконка, обложка, скриншоты 1080×1920 и описание в Консоли.

## Деньги и возраст

Выплаты идут по лицензионному соглашению: договор заключается с физическим лицом
(Яндекс выступает налоговым агентом), ИП или самозанятым. Минимальная сумма —
3000 ₽, выплата раз в месяц, доход суммируется, пока не наберётся порог.

С 16 годами договор от своего имени заключить нельзя, а без договора не открывается
даже модерация. Рабочий путь: аккаунт разработчика и договор оформляет родитель или
опекун (с его паспортом и картой), а игру и Консоль ведёшь ты. Второй вариант —
подождать 18 лет и оформить всё на себя, игра при этом уже будет готова.

Перед регистрацией стоит написать в поддержку Яндекса и уточнить формулировку:
правила платформы меняются, а ответ поддержки будет письменным подтверждением.

## Дальше

1. Собрать промо-материалы (иконка 512×512, обложка, 3–4 скриншота).
2. Создать черновик в Консоли, загрузить архив, заполнить карточку и рекламу.
3. Проверить в debug-панели: `IT`, `Game Ready`, пауза, реклама.
4. Отправить на модерацию (обычно 3–5 рабочих дней).
5. После публикации — облачные сохранения (`ysdk.getPlayer()`), лидерборд по рейтингу
   и, возможно, возврат онлайна отдельным обновлением.
