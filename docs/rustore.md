## Полное описание (до 4000 символов)

```
⚓ Морской бой — Морская арена

Та самая игра с тетрадным полем — но теперь с рейтингом, рангами и ботом, который правда умеет играть.

🎯 КАК ИГРАЕМ
• Поле 10×10 и классический флот: линкор (4), два крейсера (3), три эсминца (2) и четыре катера (1).
• Попал — стреляй ещё раз. Промахнулся — ход переходит противнику.
• Победа — потопить весь флот соперника.

🧠 УМНЫЙ СОПЕРНИК
Бот не тыкает наугад:
• ищет корабли по «шахматной» сетке;
• при попадании добивает корабль по линии;
• после потопления вычёркивает соседние клетки, где корабля быть не может.

Каждый матч бот получает рейтинг, близкий к вашему, — лёгких прогулок не будет.

📈 РЕЙТИНГ И РАНГИ
• ELO-рейтинг: победа над сильным соперником даёт больше очков, поражение от слабого отнимает больше.
• Семь рангов: Юнга → Матрос → Боцман → Штурман → Капитан → Адмирал → Легенда.
• Статистика: количество боёв, процент побед, серия побед, рекорд рейтинга.
• История последних матчей с изменением рейтинга.

🚢 РАССТАНОВКА
• Расставьте флот вручную или нажмите «Случайно».
• Кнопка поворота корабля (или клавиша R на компьютере).
• Режим «Убрать корабль» — чтобы быстро переставить один корабль.

🎨 МЕЛОЧИ, КОТОРЫЕ ПРИЯТНО
• Морская анимация, всплески от выстрелов, конфетти при победе.
• Звук синтезируется на лету — никаких тяжёлых аудиофайлов.
• Никнейм можно поменять в один тап.

📴 БЕЗ ИНТЕРНЕТА И БЕЗ РЕКЛАМЫ
• Игра работает полностью офлайн.
• Нет рекламы, аналитики и трекеров.
• Данные (ник, рейтинг, история боёв) хранятся только на вашем устройстве.

Возрастной рейтинг: 6+. Никакого насилия, крови и азартных механик — только море, корабли и логика.

Поднять якорь! ⚓
```

## Чек-лист публикации

1. Зарегистрировать аккаунт разработчика: https://console.rustore.ru (вход по VK ID, подтвердить телефон и почту).
2. «Создать приложение» → тип «Игра».
3. Загрузить APK `seabattle-1.0.0-release.apk` (RuStore сам вытащит версию и пакет).
4. Вставить название, краткое и полное описание из этого файла.
5. Загрузить иконку `assets/icon-512.png` и 4 скриншота из `docs/screenshots/`.
6. Указать политику конфиденциальности и контакты поддержки.
7. Заполнить анкету: без рекламы, без покупок, 6+.
8. Отправить на модерацию (обычно 1–3 рабочих дня).

## Важно

- **Сохраните keystore**: `android/keystore/seabattle-release.jks` + пароль.
  Без него нельзя выпустить обновление — придётся публиковать новое приложение.
- Обновления: поднять `versionCode`/`versionName` в `android/app/build.gradle`,
  собрать `assembleRelease bundleRelease` и загрузить новый APK в ту же карточку.
