# Материалы профиля Kwork

Генерируются кодом (Pillow), без внешних картинок:

```
python scripts/make-kwork-assets.py
```

- `avatar-512.png` — аватар. Загружается в [Настройки → Профиль](https://kwork.ru/settings#profile).
- `header-1920.png` — шапка профиля. Kwork требует минимум 1920×226, превью 608×72
  (8.5:1) — макет рисуется сразу в 1920×226, поэтому текст не обрезается.

Палитра — как у игры: тёмно-синий `#0b2438` → `#071a2b`, акцент бирюзовый `#3ddad7`.
Шрифт — системный Arial Bold (в `assets/fonts` только woff2, Pillow его не читает).

Тексты профиля и кворков — в `docs/freelance.md`.
