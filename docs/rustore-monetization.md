# Монетизация RuStore: фундамент без нативного SDK

Дата: 7 ноября 2026. Версия игры: 1.6.0.

Документ описывает витрину товаров, rewarded-точки и границы, которые нельзя
переходить, чтобы рейтинг ELO оставался честным. Нативный RuStore SDK в этой
итерации **не подключён**: `js/rustore.js` — это адаптер-заглушка, который
позволяет безопасно подготовить интерфейс и позже подключить мост.

## 1. Что сделано сейчас

- `js/rustore.js` — классический IIFE, наружу отдаёт `window.RuStorePlatform`.
- Без SDK: `available()` → `false`, `products()` → `[]`, остальные действия →
  `false` (через Promise), `whenReady()` → `null` через 8 секунд.
- В меню добавлены скрытые кнопки `#btn-remove-ads` и `#btn-support`.
  Они показываются только после `RuStorePlatform.available() === true`.
- Реальной оплаты нет: нативного моста нет, кнопки не видны, `purchase()`
  возвращает `false`.
- PWA-кэш поднят до `sb-v39`, `js/rustore.js` добавлен в `CORE` в `sw.js`.
- В сборках Яндекс Игр и VK/OK скрипт RuStore вырезается: там платежи не нужны.

## 2. API `window.RuStorePlatform`

| Метод | Без SDK | Назначение |
| --- | --- | --- |
| `available()` | `false` | Есть ли живой нативный мост |
| `whenReady()` | `Promise<null>` | Ждёт мост, но не дольше 8 секунд |
| `showRewarded()` | `Promise<false>` | Rewarded-видео; `true` только при полном просмотре |
| `showInterstitial()` | `Promise<false>` | Межстраничная реклама между боями |
| `purchase(id)` | `Promise<false>` | Покупка товара по строковому id |
| `restore()` | `Promise<false>` | Восстановление покупок |
| `products()` | `[]` | Синхронный каталог товаров |

`purchase()` и `restore()` считаются успешными только при строгом `true` от
моста. `showRewarded()` — тоже строго `true`, иначе награда не начисляется.

## 3. Контракт нативного моста

Нативная обёртка RuStore создаёт `window.RuStoreBridge` до загрузки `app.js`
или позже вызывает `window.onRuStoreReady(bridge)`:

```js
window.RuStoreBridge = {
  showRewarded: function () { return Promise.resolve(true); },
  showInterstitial: function () { return Promise.resolve(true); },
  purchase: function (productId) { return Promise.resolve(true); },
  restore: function () { return Promise.resolve(true); },
  products: function () {
    return [
      { id: 'remove_ads', title: 'Убрать рекламу', price: 149, currency: 'RUB' },
      { id: 'support_99', title: 'Поддержать проект', price: 99, currency: 'RUB' }
    ];
  }
};
```

Адаптер также распознаёт `window.RuStorePay` и `window.RuStoreSDK`, если
обёртка использует другое имя. `products()` у моста должен возвращать массив
синхронно; Promise в этом методе игнорируется и даёт `[]`.

## 4. Товары и цены

Цены — рекомендация для RuStore Console. Итоговую цену, валюту и НДС задаёт
магазин; в JS цены не хардкодятся, их отдаёт `products()`.

| id | Тип | Название | Цена | Что даёт |
| --- | --- | --- | --- | --- |
| `remove_ads` | Непотребляемый | Убрать рекламу | 149 ₽ | Отключает принудительную межстраничную рекламу; rewarded остаётся по желанию |
| `support_99` | Непотребляемый | Поддержать проект | 99 ₽ | Только благодарность, без бонусов и преимуществ |
| `cosmetic_sea` | Непотребляемый | Набор «Море» | 199 ₽ | Будущая косметика: скины/вода, не влияет на бой |

Кнопка `#btn-remove-ads` покупает `remove_ads`, кнопка `#btn-support` —
`support_99`. После успешной покупки флаг `removeAds` сохраняется в профиле.
Косметика в интерфейс пока не выведена — это задел на следующую итерацию.

## 5. Rewarded-точки

Rewarded-видео показывается только по явному нажатию кнопки. Нельзя запускать
его автоматически, во время хода или поверх экрана расстановки.

| Точка | Награда | Статус |
| --- | --- | --- |
| `#btn-ad-bonus` в меню | +25 ELO, раз в день | Работает через GamePush/Яндекс; для RuStore нужно подключить |
| `#btn-bonus` на результате боя | +25 ELO, раз в день | Работает через GamePush/Яндекс; для RuStore нужно подключить |
| Испытание дня | +1 попытка | План |
| Косметика | Временный доступ или скин | План |

ELO за рекламу — не покупка: награда ограничена одним разом в день и не
продаётся за деньги.

## 6. Что нельзя продавать

Запрещено продавать всё, что влияет на честность рейтинга, онлайн-боёв или
даёт игровое преимущество:

- очки ELO, рейтинг, ранг, рекорд, сезонные медали и место в таблице;
- способности и заряды: авиаудар, ПВО, дым, дополнительный выстрел;
- размер поля, состав флота, флагман, первый ход, подсмотр чужого флота;
- понижение сложности бота для фарма рейтинга;
- победы и достижения в онлайн-матчах;
- «pay-to-win»-механики любого вида.

Разрешено:

- отключение принудительной рекламы;
- добровольная поддержка разработчика без внутриигровых бонусов;
- косметика без влияния на бой;
- rewarded-реклама с ограниченной наградой, если она не продаётся за деньги.

Игра имеет возрастной рейтинг 6+. Нельзя добавлять лутбоксы, ставки, рулетки
и любые азартные механики.

## 7. Ограничения реализации

- Только классические IIFE, без ES-модулей и сборщика: корень должен
  открываться через `file://`.
- Без SDK игра обязана работать как обычная офлайн-игра.
- Таймаут готовности моста — 8 секунд, таймаут рекламы и покупки — 20 секунд.
- Одновременно может идти только один rewarded-показ.
- `js/rustore.js` добавлен в PWA-кэш; при следующих правках поднимать
  `VERSION` в `sw.js` и `SW_VERSION` в `js/app.js` синхронно.
- Сборки Яндекс Игр и VK/OK вырезают `js/rustore.js` из `index.html`.
- Пока RuStore-реклама не подключена к `app.js`: существующие rewarded и
  interstitial идут через `window.GamePlatform || window.YandexGame`.
  Это осознанно: сначала фундамент, потом нативный мост.

## 8. Порядок подключения нативного SDK

1. Собрать RuStore-версию с нативным плагином оплаты и рекламы.
2. Внедрить `window.RuStoreBridge` (или вызвать `onRuStoreReady`).
3. Завести товары в RuStore Console с теми же id: `remove_ads`, `support_99`.
4. Задать цены и проверить покупку в тестовом окружении магазина.
5. Подключить `RuStorePlatform.showRewarded()` / `showInterstitial()` к
   существующим точкам в `app.js` вместо/вместе с `YG`.
6. Проверить `restore()` после переустановки.
7. Обновить карточку RuStore: «содержит рекламу — да», «встроенные покупки — да»,
   ссылка на `privacy.html`.
8. Поднять `versionCode`/`versionName` и PWA-кэш, прогнать `npm.cmd test`.

## 9. Проверка

- `npm.cmd test` — unit-тесты `tests/rustore.test.mjs`.
- Без SDK: кнопки `#btn-remove-ads` и `#btn-support` не видны.
- `RuStorePlatform.available() === false`, `products()` возвращает `[]`.
- С фейковым мостом в тестах: кнопки показываются, методы возвращают значения
  моста, rewarded не запускается дважды.
- На `file://` игра открывается и не падает без `js/rustore.js`.

## 10. Риски

- **Юридические и налоговые.** Покупки в RuStore требуют статуса самозанятого
  или ИП и корректных цен с НДС. Не включать реальные продажи без проверки.
- **Модерация.** Карточка `docs/rustore.md` сейчас говорит «без рекламы и
  покупок». После подключения SDK её нужно обновить, иначе расхождение с
  фактическим поведением.
- **Возраст 6+.** Реклама и покупки должны соответствовать правилам RuStore
  для детской аудитории; нельзя давить на ребёнка и обещать преимущества.
- **Честность ELO.** Любая платная механика, влияющая на рейтинг, ломает
  основной продукт. Продавать можно только косметику, отключение рекламы
  и добровольную поддержку.
- **Опубликованные артефакты.** RuStore 1.5.0 и архив VK v3 не трогаем:
  изменения входят только в следующую сборку после модерации.
