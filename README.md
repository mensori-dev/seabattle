# ⚓ Морской бой — Морская арена

Браузерная игра «Морской бой» против бота: расстановка флота, умный соперник,
плавные анимации, звук, никнеймы и рейтинг ELO с рангами в духе Brawl Stars.

**Играть онлайн:** https://mensori-dev.github.io/seabattle/

## Запуск

Просто открой **`index.html`** двойным кликом — всё работает без сборки и установки.

Если браузер капризничает с `file://`, подними дев-сервер:

```
npm run dev
```

и открой http://localhost:5173.

## Установка на телефон (PWA)

Игра — PWA: ставится на домашний экран и работает офлайн.

1. Открой опубликованную ссылку в браузере телефона.
2. **Android / Chrome**: меню ⋮ → «Установить приложение».
3. **iPhone / Safari**: «Поделиться» → «На экран Домой».

Иконки пересобираются скриптом `python scripts/make-icons.py` (нужен Pillow).

## Android-приложение (APK)

Обёртка — Capacitor. Нужны **JDK 21** (Capacitor 8 не собирается на 17) и Android SDK (platform 36, build-tools 36).

```
npm run www            # собрать www/ из корня
npx cap sync android   # скопировать веб-ассеты в нативный проект
cd android
gradlew assembleDebug  # APK → app/build/outputs/apk/debug/app-debug.apk
```

Иконки и splash для Android: `npx capacitor-assets generate --android --assetPath resources`.

Для Google Play и RuStore нужен `bundleRelease` (AAB) и подпись keystore, а также targetSdk 36 — он уже выставлен в `android/variables.gradle`.

Параметры подписи лежат в `android/keystore.properties` (в git не коммитится),
сам ключ — `android/keystore/seabattle-release.jks`. **Потеряешь ключ или пароль —
обновления приложения станут невозможны.**

```
cd android
gradlew assembleRelease bundleRelease --no-daemon
# APK → app/build/outputs/apk/release/app-release.apk
# AAB → app/build/outputs/bundle/release/app-release.aab
```

Готовые файлы для магазинов складываются в `dist/` (`*.apk`, `*.aab` — в git не идут).

## Что внутри

- **Поле 10×10**, классический флот: линкор (4), 2 крейсера (3), 3 эсминца (2), 4 катера (1).
- **Расстановка**: тап/клик по клетке, поворот (`R` или кнопка), «Случайно», «Очистить», режим удаления корабля.
- **Умный бот**: ищет корабли по «шахматной» сетке, при попадании добивает по линии, после потопления исключает соседние клетки.
- **Правила**: попадание даёт дополнительный выстрел, промах передаёт ход.
- **ELO-рейтинг**: K = 32, старт 1000. Победа над сильным соперником даёт больше очков.
- **Ранги**: Юнга → Матрос → Боцман → Штурман → Капитан → Адмирал → Легенда.
- **Профиль**: ник (редактируется), статистика, серия побед, рекорд, история последних боёв — всё хранится в `localStorage`.
- **Звук**: синтезируется через Web Audio API, без аудиофайлов; есть кнопка mute.
- **Адаптивность**: отдельные раскладки для телефона и компьютера.

## Управление

| Действие | Как |
| --- | --- |
| Поставить корабль | Тап/клик по клетке поля |
| Повернуть корабль | Кнопка «Горизонтально/Вертикально», `R` или правый клик |
| Убрать корабль | Кнопка «Убрать корабль», затем тап по кораблю |
| Выстрел | Тап/клик по полю противника |
| Сдаться | Кнопка «Сдаться» под полями |
