# Тексты для карточки игры

Копируй поля в консоль как есть — здесь ровно те формулировки, которые
проверяет модерация (длина, орфография, соответствие геймплею).

## Название — 27 символов (лимит 50)

```
Морской бой — Морская арена
```

Название должно совпадать с игрой и со всеми картинками. В самой игре
заголовок вкладки и логотип — «Морской бой — Морская арена», на обложке
написано то же самое. Если консоль скажет, что название занято, добавь
подзаголовок, например «Морской бой — Морская арена: дуэль с ботом»,
и поменяй его ещё и в `index.html`.

## Краткое описание — 59 символов (лимит 70)

```
Морской бой с ботом и рейтингом: расставь флот и топи врага
```

## Описание для поиска (SEO) — 120 символов (50–160)

```
Классический морской бой с ботом: расставляй флот, находи корабли противника и поднимайся в рейтинге от юнги до легенды.
```

## Об игре — 523 символа (100–1000)

```
Морской бой — Морская арена: классическая настольная игра против бота.
Расставь флот на поле 8×8, 10×10 или 12×12, угадывай клетки противника, топи корабли и получай рейтинг ELO за каждый бой.
Соперники отличаются характером: от осторожного новичка до адмирала, который бьёт точно и не прощает ошибок. Побеждай, поднимайся в рангах от юнги до легенды и собирай достижения: первая победа, идеальный бой, серия из трёх побед.
Перед боем выбирай тактику — авиаудар, ПВО или дым. Есть ежедневный бонус, испытание дня и статистика точности. Игра работает без интернета, управление — одним касанием.
```

## Как играть — 763 символа (100–1000)

```
1. Нажми «В бой» — откроется расстановка флота. Нажми «Случайно», чтобы игра расставила корабли сама, или расставляй вручную: выбери корабль в доке и нажми на клетку. Кнопка «Вправо» (или клавиша R) поворачивает корабль.
2. Корабли не должны касаться друг друга даже углами. Если клетка занята, игра подсветит ошибку.
3. Когда флот готов, нажми «В бой». Ты и противник стреляете по очереди: попадание даёт дополнительный выстрел.
4. Точка — промах, огонь — попадание, тёмный корабль — потоплен. При потоплении открывается весь корабль.
5. Потопи все корабли противника раньше, чем он потопит твои. За победу рейтинг растёт, за поражение — падает.
6. В настройках меняются поле (8×8, 10×10, 12×12), флот, сложность бота, тема, звук и анимации. С тактикой перед боем выбери 2 способности из 3: авиаудар, ПВО или дым. На компьютере играешь мышью, на телефоне — касанием.
```

## Категории

- Основная: **Настольные игры** (в консоли — «Настольные»).
- Дополнительная: **Логические**.

Если в списке консоли «Настольных» нет, выбирай «Логические» — подойдёт
и то и другое, но не выбирай аркады и экшены: игра пошаговая.

## Возрастной рейтинг

```
6+
```

Корабли абстрактные, крови и жестокости нет. 0+ тоже допустим, но 6+
модерация принимает спокойнее для игр с «боем» в названии.

## Язык

```
Русский
```

Игра определяет язык через `environment.i18n.lang` на старте (требование
2.14), но переведена только на русский. В поле «Игра переведена на»
оставляй **только русский**: за неперевод заявленного языка отклоняют.

## Платформы и ориентация

- Поддерживаемые платформы: **Смартфоны и планшеты** (это основная аудитория).
- Ориентация: **Портретная**.
- Десктоп включай только если готов проверять растягивание поля на весь
  экран (требование 1.6.2). Скриншоты 1600×900 в папке `screens/` для этого есть.

## Монетизация

- Реклама: **да** (РСЯ).
- Инап-покупки: **нет** — в игре их нет.
- Облачные сохранения: **нет** — прогресс в localStorage, но сохраняется
  сразу после каждого действия (требование 1.9).

## Комментарий модератору

```
Игра только на русском языке, автоопределение языка через environment.i18n.lang вызывается на старте.
Онлайна в этой сборке нет: игра идёт против бота.
Реклама: полноэкранная между матчами — не раньше второго боя и не чаще одного раза в 90 секунд; видео за вознаграждение — по кнопке «Бонус за рекламу: +25 к рейтингу» на экране результата, раз в день.
При показе рекламы и при потере фокуса звук и геймплей ставятся на паузу (game_api_pause, visibilitychange).
Данные игрока (ник, рейтинг, достижения) хранятся в localStorage, на сервер ничего не отправляется.
Внешних ссылок, авторизации через сторонние сервисы и сторонней рекламы нет.
```
