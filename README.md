# ⚓ Морской бой — Морская арена

Браузерная игра «Морской бой» против бота: расстановка флота, умный соперник,
плавные анимации, звук, никнеймы и рейтинг ELO с рангами в духе Brawl Stars.

**Играть онлайн:** https://mensori-dev.github.io/seabattle/

## Запуск

Просто открой **`index.html`** двойным кликом — всё работает без сборки и установки.

Если браузер капризничает с `file://`, подними дев-сервер:

```
npm run dev
```

и открой http://localhost:5173.

## Игра с другом онлайн

В меню есть кнопка **«🌐 Играть с другом»**: один создаёт комнату и получает
4-значный код, второй вводит его — и вы играете в реальном времени.

- Выстрелы считает сервер, поэтому чужой флот нельзя подсмотреть через DevTools.
- Онлайн-матчи не меняют ELO — рейтинг остаётся только за бои с ботом.
- Офлайн-режим, PWA и APK работают как раньше: сервер нужен только для онлайна.

Локально:

```
npm run server   # Deno-сервер на http://127.0.0.1:8000
npm run dev      # сайт на http://localhost:5173
npm run test:online  # протокол-смоук против запущенного сервера
```

Деплой на бесплатный Deno Deploy, настройка `PROD_URL` и описание протокола —
в [docs/online.md](docs/online.md).

## Установка на телефон (PWA)

Игра — PWA: ставится на домашний экран и работает офлайн.

1. Открой https://mensori-dev.github.io/seabattle/ в браузере телефона.
2. **Android / Chrome**: меню ⋮ → «Установить приложение».
3. **iPhone / Safari**: «Поделиться» → «На экран Домой».

На iPhone в Safari внизу меню появляется подсказка «📱 Добавь на iPhone» —
её можно закрыть, и она больше не покажется. В установленном режиме игра
открывается на весь экран, с заставкой из `assets/splash/` (9 размеров
актуальных iPhone) и без адресной строки. Без установки iOS может очищать
данные сайта после недели простоя — поэтому лучше добавить на домашний экран,
тогда рейтинг и прогресс сохранятся.

Нативное приложение для App Store / TestFlight собирается только на macOS
(Xcode + Apple Developer Account). На Windows доступен PWA-вариант — для друзей
с iPhone он ставится точно так же, как на Android.

Иконки и заставки пересобираются скриптом `python scripts/make-icons.py` (нужен Pillow).

## Android-приложение (APK)

Обёртка — Capacitor. Нужны **JDK 21** (Capacitor 8 не собирается на 17) и Android SDK (platform 36, build-tools 36).

```
npm run android:apk        # подписанный release APK + AAB → dist/
npm run android:apk -- --apk   # только APK, быстрее
npm run android:apk -- --debug # debug-сборка для локальных тестов
```

Скрипт сам собирает `www/`, вызывает `cap sync` и подписывает release-сборку.
Готовые файлы: `dist/seabattle-<версия>-release.apk` и `.aab`.
**Друзьям и в RuStore отправляй только release-APK:** debug-сборка подписана
другим ключом и не устанавливается поверх release-версии.

Иконки и splash для Android: `npx capacitor-assets generate --android --assetPath resources`.

Для Google Play и RuStore нужен `bundleRelease` (AAB) и подпись keystore, а также targetSdk 36 — он уже выставлен в `android/variables.gradle`.

Параметры подписи лежат в `android/keystore.properties` (в git не коммитится),
сам ключ — `android/keystore/seabattle-release.jks`. **Потеряешь ключ или пароль —
обновления приложения станут невозможны.**

```
cd android
gradlew assembleRelease bundleRelease --no-daemon
# APK → app/build/outputs/apk/release/app-release.apk
# AAB → app/build/outputs/bundle/release/app-release.aab
```

Готовые файлы для магазинов складываются в `dist/` (`*.apk`, `*.aab` — в git не идут).

## Что внутри

- **Поле 10×10**, классический флот: линкор (4), 2 крейсера (3), 3 эсминца (2), 4 катера (1).
- **Расстановка**: тап/клик по клетке, поворот на 4 стороны (`R`, колесо или кнопка),
  авто-разворот у края поля, «Случайно», «Очистить», режим удаления корабля.
- **Умный бот** с тремя уровнями: «Легко» стреляет почти наугад, «Обычно» ищет
  по «шахматной» сетке и добивает по линии, «Сложно» ещё и выбирает клетки
  с максимальной плотностью возможных кораблей.
- **Правила**: попадание даёт дополнительный выстрел, промах передаёт ход.
- **ELO-рейтинг**: K = 32, старт 1000. Победа над сильным соперником даёт больше очков.
- **Ранги**: Юнга → Матрос → Боцман → Штурман → Капитан → Адмирал → Легенда.
- **Профиль**: ник (редактируется), статистика, серия побед, рекорд, история последних боёв — всё хранится в `localStorage`.
- **Настройки** (⚙️ в шапке): громкость, отключение анимаций, сложность бота,
  сброс статистики или всего прогресса.
- **Звук**: синтезируется через Web Audio API, без аудиофайлов; есть кнопка mute.
- **Понятные выстрелы**: клетка вспыхивает, остальное поле притухает, над ней
  всплывает 💥/🌊; на телефоне поле само подкручивается к месту выстрела.
- **Адаптивность**: отдельные раскладки для телефона и компьютера, учтены
  «челка» и системные полосы Android и iPhone.
- **Установка как приложение**: Android — через «Установить», iPhone — через
  «Поделиться → На экран Домой»; на iPhone есть заставки при запуске и подсказка.

## Управление

| Действие | Как |
| --- | --- |
| Поставить корабль | Тап/клик по клетке поля |
| Повернуть корабль | Кнопка «Вправо/Вниз/…», `R`, колесо мыши или правый клик — 4 направления по кругу |
| Развернуть в другую сторону | `Shift` + кнопка/`R`/клик (сразу на 180°) |
| У края поля | Корабль разворачивается сам, чтобы влезть |
| Убрать корабль | Кнопка «Убрать корабль», затем тап по кораблю |
| Выстрел | Тап/клик по полю противника |
| Настройки | ⚙️ в правом верхнем углу |
| Сдаться | Кнопка «Сдаться» под полями |
