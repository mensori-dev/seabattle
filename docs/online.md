# Онлайн: игра с другом по коду комнаты

Онлайн — отдельный режим рядом с игрой против бота. Офлайн-игра не меняется:
`file://`, PWA и APK работают без сервера.

```
js/online.js        клиент: WebSocket, комнаты, события (window.Online)
server/main.ts      сервер: комнаты, проверка флота, подсчёт выстрелов
```

## Как это устроено

1. Игрок A нажимает «Создать комнату» → сервер выдаёт 4-значный код.
2. Игрок B вводит код → оба попадают на расстановку.
3. Каждый отправляет свой флот. Сервер проверяет состав, границы, пересечения
   и касания (даже углами).
4. Когда оба флота приняты, сервер случайно выбирает первого и присылает `begin`.
5. Выстрелы считает **сервер**: клиент не знает чужой флот и не может подсмотреть
   его через DevTools. Клиент получает только `miss` / `hit` / `sunk` и клетки
   потопленного корабля.
6. Промах передаёт ход, попадание оставляет его. Победа — когда потоплены все
   10 кораблей. Комната после боя удаляется.
7. Онлайн-матчи не меняют ELO и не попадают в историю: рейтинг начисляется
   только в боях с ботом.

Сообщения (JSON, поле `t`):

| От клиента | Что значит |
| --- | --- |
| `create` / `join` | создать комнату / войти по коду |
| `fleet` | расстановка: `[{ size, cells: [[x, y], …] }, …]` |
| `shot` | выстрел `{ x, y }` |
| `surrender` / `leave` | сдаться / выйти |

| От сервера | Что значит |
| --- | --- |
| `room` | код комнаты и твой индекс |
| `wait` / `start` | ждём второго / второй зашёл |
| `fleetOk` / `foeReady` | флот принят / соперник готов |
| `begin` | бой начался, `first` — твой ли ход |
| `shot` | результат выстрела (`mine: true` — твой) |
| `turn` | чей ход |
| `end` / `foeLeft` | конец боя / соперник вышел |
| `error` | текст ошибки для игрока |

## Локальный запуск

Терминал 1 — сервер:

```
deno run --allow-net --allow-env server/main.ts
```

Терминал 2 — сайт:

```
npm run dev
```

Проверка протокола без браузера — `npm run test:online` (сервер должен быть
запущен; скрипт `scripts/online-smoke.mjs`, можно указать свой URL аргументом).

Открой http://localhost:5173 в двух вкладках (или на двух устройствах в одной
сети — тогда замени `127.0.0.1` в `js/online.js` на IP компьютера).
Первая вкладка: «Играть с другом» → «Создать комнату». Вторая: ввести код.

Проверка сервера: http://127.0.0.1:8000/health → `{"ok":true,"rooms":0}`.

## Деплой на Deno Deploy (бесплатно)

Нужен аккаунт GitHub или Google — карта не требуется. Бесплатного лимита
(100 000 запросов в сутки) хватает с большим запасом: одна партия — это
несколько десятков сообщений.

### Вариант 1 — через сайт (без установки)

1. Открой https://dash.deno.com и войди.
2. **New Project** → **Playground** (или «Deploy from playground»).
3. Вставь содержимое `server/main.ts` целиком.
4. Нажми **Deploy**, дай проекту имя, например `seabattle-online`.
5. Получишь адрес вида `https://seabattle-online.deno.dev`.
6. Проверь `https://seabattle-online.deno.dev/health` — должно вернуться
   `{"ok":true,"rooms":0}`.

### Вариант 2 — через CLI

```
deno install -gArf jsr:@deno/deployctl
deployctl deploy --project=seabattle-online server/main.ts
```

### Подключить адрес в игре

В `js/online.js` заполни константу:

```js
var PROD_URL = 'wss://seabattle-online.deno.dev/ws';
```

Важно: `wss://` (не `https://`) и обязательный `/ws` на конце. После правки
подними версию кэша в `sw.js` (`VERSION`), иначе у установленных PWA останется
старый клиент.

## Что важно помнить

- Сервер хранит комнаты в памяти. Перезапуск/засыпание инстанса закрывает
  активные комнаты — для игры с друзьями это нормально.
- Комната живёт 2 часа, потом удаляется фоновой уборкой.
- Ники чистятся от управляющих символов и `<`/`>`, длина — до 16 символов.
- Один игрок — одно соединение: при обрыве соперник получает `foeLeft`.
- Читить через клиент нельзя: флот и выстрелы проверяет сервер.
