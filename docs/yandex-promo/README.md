# Публикация в Яндекс Играх — пошагово

Папка собрана `npm run yandex:promo`. Здесь всё, что просит консоль:
картинки, видео и тексты. Ничего в OneDrive не отправляется.

## Что в папке

| Файл | Куда в консоли | Требование |
|---|---|---|
| `icon-512.png` | Иконка | 512×512, PNG |
| `cover-800x470.png` | Обложка | 800×470, PNG, не скриншот |
| `hero-1560x520.png` | Картинка для страницы игры | 1560×520, PNG/JPG |
| `screens/mobile-01…06-*.png` | Скриншоты (мобильные) | 1080×1920, 9:16 |
| `screens/desktop-01…02-*.png` | Скриншоты (десктоп) | 1600×900, 16:9 |
| `video/seabattle-16x9.mp4` | Горизонтальное видео | 16:9, MP4, до 28 с |
| `video/seabattle-9x16.mp4` | Вертикальное видео | 9:16, MP4, до 28 с |
| `TEXTS.md` | Тексты полей | — |
| этот файл | инструкция | — |

Архив самой игры лежит в этой же папке: `seabattle-yandex-1.4.0.zip`
(156 КБ, `index.html` в корне, без пробелов и русских букв в именах).

## Шаг 1. Аккаунт (делает отец, ему 18+)

1. Нужен **Яндекс ID с логином Яндекса** (`…@yandex.ru`). Если аккаунт
   регистрировался через Gmail/Mail.ru или «упрощённо», сначала полная
   регистрация: <https://id.yandex.ru> → «Полная регистрация».
   С чужими почтовыми доменами реклама может не подключиться.
2. Открыть <https://games.yandex.ru/console> и войти этим Яндекс ID.
3. Придумать **имя разработчика** — оно будет видно игрокам в карточке игры.
   Латиница, цифры, пробел, дефис, подчёркивание. Без почты и ссылок.
4. Принять условия (лицензионное соглашение и правила размещения).
5. Нажать **Создать профиль**.

На один Яндекс ID — один аккаунт разработчика. Если позже захочешь свой,
понадобится отдельный Яндекс ID.

## Шаг 2. Договор — без него нет модерации

Профиль даёт только черновик. Кнопка отправки на модерацию появится,
когда заключён договор.

Так как договор оформляет **физическое лицо** (отец), единая лицензионная
схема в консоли для этого случая недоступна — нужна регистрация в
**Рекламной сети Яндекса (РСЯ)**: <https://partner.yandex.ru>.

Что заполняется там (понадобятся документы отца):

- паспортные данные и ИНН;
- адрес регистрации;
- телефон и почта;
- реквизиты для выплат (карта или счёт).

Дальше Яндекс проверяет данные и заключает договор — обычно несколько
рабочих дней. Статус видно в консоли: **Профиль → Единая лицензионная
схема** (или в личном кабинете РСЯ).

Налоги: для физлица Яндекс — налоговый агент и удерживает НДФЛ (13%),
самому ничего сдавать не нужно. Если оформить самозанятость, ставка 6%
и чеки формирует Яндекс — но это уже отдельная история, для старта
не обязательно.

## Шаг 3. Черновик игры

В консоли: **Игры → Добавить игру**.

1. **Название, описания, теги, ключевые слова** — копируй из `TEXTS.md`.
   Там уже посчитаны длины под лимиты консоли.
2. **Архив** — `seabattle-yandex-1.4.0.zip` из этой папки. Не переименовывай файлы
   внутри и не пересобирай архив «вручную»: `index.html` должен лежать
   в корне архива, путь — с прямыми слэшами.
3. **Иконка** — `icon-512.png`.
4. **Обложка** — `cover-800x470.png`.
5. **Картинка для страницы игры** — `hero-1560x520.png` (если поле есть
   в форме; необязательное).
6. **Скриншоты** — загрузи `mobile-01…06`. Порядок: расстановка, бой,
   результат, меню, достижения, правила. Первый скриншот показывается
   в каталоге, поэтому первым идёт геймплей.
   Десктопные (`desktop-*`) нужны только если включишь платформу «Компьютеры».
7. **Видео** — `seabattle-16x9.mp4` обязательно, `seabattle-9x16.mp4`
   по желанию. Оба короче 28 секунд и легче лимита 400 кбит/с.
8. **Платформы и ориентация** — смартфоны и планшеты, портретная.
9. **Язык** — только русский. **Возраст** — 6+.
10. **Монетизация** — реклама включена, инап-покупок нет, облачных
    сохранений нет.
11. **Комментарий модератору** — текст в конце `TEXTS.md`.

## Шаг 4. Проверка перед отправкой

В консоли у игры есть кнопка **Открыть с debug-панелью**. Проверь:

- индикатор языка **文 зелёный** сразу на старте (это требование 2.14);
- игра открывается на весь экран, нет полос прокрутки и обрезанных кнопок;
- рекламы нет в первом бою; после второго боя появляется полноэкранная,
  и повторно — не чаще раза в 90 секунд;
- на экране результата есть кнопка «🎁 Бонус за рекламу: +25 к рейтингу»,
  после просмотра рейтинг растёт, второй раз за день бонус не даёт;
- при показе рекламы и при переключении вкладки игра встаёт на паузу,
  звук пропадает;
- в консоли браузера нет красных ошибок.

Если что-то не так — правь код, пересобирай `npm run yandex`, заливай архив
заново. Черновик можно перезаписывать сколько угодно до отправки.

## Шаг 5. Модерация

Нажать **Отправить на модерацию**. Обычно 3–5 рабочих дней.

Частые причины отказа и что делать:

- **Нет автоопределения языка** — индикатор 文 красный. У нас читается
  `environment.i18n.lang` на старте; проверь именно на debug-панели.
- **Реклама мешает** — нельзя показывать чаще, чем раз в минуту-полторы,
  и нельзя в первом бою. У нас между матчами и по кнопке.
- **Скриншоты не показывают геймплей** — не добавляй картинки «из головы»,
  бери только из этой папки.
- **Ссылки наружу** — в сборке их нет: ни сайта, ни APK, ни соцсетей,
  Google Fonts вырезаны, шрифты локальные.
- **Название занято** — добавь подзаголовок, но поменяй его и в игре
  (`index.html`, логотип), иначе не совпадёт с карточкой.
- **Игра «в разработке»** — не оставляй кнопок-заглушек и пустых экранов.

Если отказ непонятен — в консоли есть чат поддержки, туда можно писать
по-русски.

## Шаг 6. Деньги

- Выплаты — **раз в месяц**, минимальная сумма **3000 ₽**.
  Не набралось — сумма переносится на следующий месяц.
- Приходит в течение **20 рабочих дней** следующего месяца.
- Считается доход по всем играм сразу.
- Статистика: консоль → **Общий доход**.

Первые деньги реально увидеть не сразу: показы рекламы зависят от
трафика, а трафик — от того, как часто игру показывают в каталоге.
Первые недели лучше смотреть на удержание и рейтинг игры, а не на рубли.

## Обновления

```powershell
npm run yandex        # пересобрать dist/yandex + zip
npm run yandex:promo  # пересобрать картинки и видео (нужен Chrome)
npm test              # проверить, что ничего не сломалось
```

В консоли: **Игры → твоя игра → новая версия**, загрузить новый архив,
поднять номер версии. Название и карточку менять не нужно.

## Чего не делать

- Не добавлять ссылки на сайт, APK/IPA, сторы, соцсети — за это снимают.
- Не вставлять рекламу сторонних сетей и свои «баннеры».
- Не использовать скриншоты из других игр и картинки не по теме.
- Не обещать в текстах денег, призов и «лучшую игру года».
- Не менять название после публикации без пересборки игры.
- Не путать эту сборку с обычной игрой: онлайн-режим есть только
  в `index.html` из корня проекта, в архив для Яндекса он не попадает.
