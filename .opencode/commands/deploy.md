---
description: Подготовить и выложить игру на GitHub Pages (только после подтверждения)
---

Подготовь деплой «Морского боя» на GitHub Pages.

1. Проверь `git status`, `gh auth status` и наличие remote.
2. Убедись, что `npm test` проходит.
3. Покажи пользователю план: репозиторий, ветка, что будет опубликовано.
4. Ничего не пушь и не создавай без явного «да».
5. После подтверждения: создай репозиторий через `gh repo create`, запушь `main`,
   включи Pages (ветка `main`, папка `/`) и выдай ссылку.
