Проверь текущее состояние проекта «Морской бой».

1. Запусти `npm test` и покажи результат.
2. Если есть Deno и `server/main.ts`: подними `npm run server` в фоне, прогони
   `npm run test:online`, останови сервер, покажи результат.
3. Если доступны браузерные инструменты — подними `npm run dev`, открой игру и пройди смоук:
   меню → «В БОЙ» → «Случайно» → «В БОЙ» → выстрел по полю противника.
4. Проверь консоль на ошибки.
5. Дай короткий отчёт: что прошло, что упало, что подозрительно.

Ничего не редактируй.
