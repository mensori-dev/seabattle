# Seabattle Dev

## Когда использовать

Любая работа в этом репозитории: правки движка, UI, тестов, деплой.

## Контекст

Игра без сборки: `index.html` + `style.css` + `js/engine.js` + `js/app.js`.
Открывается как `file://`, поэтому браузерные скрипты — классические IIFE, без `import`.

## Проверка изменений

1. `npm test`
2. `npm run dev` → http://localhost:5173
3. Смоук: меню → «В БОЙ» → «Случайно» → «В БОЙ» → выстрел → ход бота.
4. Консоль без ошибок, мобильная ширина 390px.

## Движок

- Флот: `[4,3,3,2,2,2,1,1,1,1]`, касания запрещены (включая диагонали).
- `fire()` возвращает `{result: 'miss'|'hit'|'sunk', ship?}`.
- Бот: parity-поиск, добивание по линии, исключение клеток вокруг потопленного.
- ELO: K=32, старт 1000, ранги в `RANKS`.

## UI

- Экраны переключаются `showScreen()`.
- Анимации: `incoming` → `miss`/`hit` → `sunk`; задержки через `--sd`.
- Звук — Web Audio, без файлов, mute в профиле.
- Ход бота защищён `matchSeq`; не убирать проверки.

## Релиз

- Только после подтверждения пользователя.
- PWA: `manifest.webmanifest`, `sw.js`, иконки 192/512.
- GitHub Pages: ветка `main`, папка `/`.
- APK (позже): Capacitor, `npx cap add android`.

## Чего не делать

- Не тащить фреймворки и бандлеры без просьбы.
- Не менять ключ localStorage без миграции.
- Не пушить и не деплоить без «да».
