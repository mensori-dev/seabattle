# «Морской бой» 1.4.0 — Блок 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить 1.4.0 с редактором корабля на расстановке, однозначной индикацией выстрелов, фоновой музыкой, стабильным онлайном и исправленным подключением в APK.

**Architecture:** Правила поворота живут в `js/engine.js` как чистые функции. UI редактора, музыкальные настройки и онлайн-состояния — в `js/app.js`. Процедурная музыка вынесена в новый классический IIFE `js/music.js`. Онлайн-клиент получает heartbeat и защиту от событий старого сокета; серверный протокол комнат не меняется.

**Tech Stack:** Vanilla HTML/CSS/JS без сборщика, WebAudio, Deno WebSocket-сервер, node:test, Capacitor Android.

**Spec:** `docs/superpowers/specs/2026-11-04-seabattle-1.4.0-block1-design.md`

## Global Constraints

- Браузерные скрипты — классические IIFE, без `import`/`export`.
- `js/engine.js` не трогает DOM; `js/app.js` не содержит правил игры.
- Ключ профиля `seabattle.profile.v2` не меняется; новые поля добавляются в `defaultProfile()`.
- Версия кэша: `VERSION` в `sw.js` и `SW_VERSION` в `js/app.js` должны совпадать и быть `sb-v21` после Task 7.
- UI на русском, mobile-first, новые тач-цели не меньше 44 px.
- `prefers-reduced-motion: reduce` отключает масштабирование и пульсацию.
- Сборка Яндекс Игр собирается из тех же исходников, без онлайна и PWA; `js/music.js` в ней обязателен.
- Сервер остаётся авторитетным: клиент не получает чужой флот.
- Никаких внешних аудиофайлов и сторонних библиотек.
- `git push`, деплой и релиз — только после отдельного подтверждения пользователя.
- Тесты запускать через `npm.cmd test` в PowerShell; логи перенаправлять в файл и читать UTF-8.

## Review Focus

- Поворот у края поля не должен оставлять клетки за границей — Task 1, тест «поворот у нижнего края».
- Поворот вплотную к другому кораблю или углом должен отклоняться без изменения доски — Task 1, тест «поворот не разрешён».
- После отправки флота в онлайне расстановка не должна меняться — Task 2, guard `placementLocked()` + браузерный смоук.
- Скрытая вкладка не должна ложно рвать матч heartbeat-ом — Task 6, тест паузы сторожка + смоук с переключением вкладки.
- Музыка не должна стартовать до жеста пользователя — Task 4, тест `start()` без контекста + браузерный смоук.

```js
function shipAt(board, x, y) {
  if (!inBounds(x, y)) return null;
  const id = board.grid[y][x];
  return id >= 0 ? board.ships[id] || null : null;
}

function canPlaceCells(board, cells, ignoreShipId) {
  const ignore = typeof ignoreShipId === 'number' ? ignoreShipId : -1;
  for (const c of cells) {
    if (!inBounds(c.x, c.y)) return false;
    for (let dy = -1; dy <= 1; dy++) {
      for (let dx = -1; dx <= 1; dx++) {
        const nx = c.x + dx;
        const ny = c.y + dy;
        if (!inBounds(nx, ny)) continue;
        const id = board.grid[ny][nx];
        if (id !== -1 && id !== ignore) return false;
      }
    }
  }
  return true;
}
```

`rotateShip`:

```js
function rotateShip(board, shipId, dir) {
  const ship = board.ships[shipId];
  if (!ship) return { ok: false, reason: 'missing' };
  if (ship.size <= 1) return { ok: true, ship };

  const xs = ship.cells.map((c) => c.x);
  const ys = ship.cells.map((c) => c.y);
  const minX = Math.min(...xs);
  const minY = Math.min(...ys);
  const wasHorizontal = ship.horizontal;

  const cells = [];
  for (let i = 0; i < ship.size; i++) {
    cells.push(wasHorizontal
      ? { x: minX, y: minY + i }
      : { x: minX + i, y: minY });
  }

  // сдвигаем линию внутрь поля, если она вылезла за край
  const overflowY = Math.max(0, (minY + ship.size) - SIZE);
  const overflowX = Math.max(0, (minX + ship.size) - SIZE);
  for (const c of cells) {
    c.y -= overflowY;
    c.x -= overflowX;
  }

  if (!canPlaceCells(board, cells, shipId)) return { ok: false, reason: 'collision' };

  for (const c of ship.cells) board.grid[c.y][c.x] = -1;
  ship.cells = cells;
  ship.horizontal = !wasHorizontal;
  if (dir === 'left') ship.cells.reverse();
  for (const c of cells) board.grid[c.y][c.x] = shipId;
  return { ok: true, ship };
}
```

2. Добавить функции:

```js
function shipEditorEl() { return $('#ship-editor'); }
function shipEditorPanel() { return $('#ship-editor .ship-editor-panel'); }

function placementLocked() {
  return state.mode === 'online' && !!(state.net && state.net.fleetSent);
}

function setPlacementLocked(locked) {
  const screen = $('#screen-place');
  if (screen) screen.classList.toggle('is-fleet-sent', !!locked);
  if (locked) closeShipEditor(false);
}

function refreshEditorSelection() {
  $$('#board-place .cell').forEach((cell) => cell.classList.remove('ship-selected'));
  const ed = state.placement && state.placement.editor;
  if (!ed) return null;
  const ship = state.playerBoard.ships[ed.shipId];
  if (!ship) return null;
  ship.cells.forEach((c) => {
    const cell = boards.place.children[c.y * Engine.SIZE + c.x];
    if (cell) cell.classList.add('ship-selected');
  });
  return ship;
}

function positionEditorPanel() {
  const panel = shipEditorPanel();
  const ship = refreshEditorSelection();
  if (!panel || !ship) return;
  panel.classList.toggle('is-sheet', window.innerWidth < 640);
  panel.style.left = '';
  panel.style.top = '';
  if (panel.classList.contains('is-sheet')) return;

  const rects = ship.cells.map((c) => boards.place.children[c.y * Engine.SIZE + c.x].getBoundingClientRect());
  const left = Math.min(...rects.map((r) => r.left));
  const top = Math.min(...rects.map((r) => r.top));
  const right = Math.max(...rects.map((r) => r.right));
  const bottom = Math.max(...rects.map((r) => r.bottom));
  const pw = panel.offsetWidth;
  const ph = panel.offsetHeight;
  let py = top - ph - 12;
  if (py < 8) py = bottom + 12;
  py = Math.min(py, window.innerHeight - ph - 8);
  const px = clamp(left + (right - left) / 2 - pw / 2, 8, window.innerWidth - pw - 8);
  panel.style.left = px + 'px';
  panel.style.top = py + 'px';
}

function openShipEditor(ship) {
  if (!state.placement || placementLocked()) return;
  state.placement.editor = { shipId: ship.id };
  const editor = shipEditorEl();
  if (editor) editor.hidden = false;
  $('#screen-place').classList.add('is-ship-edit');
  boards.place.classList.add('is-editing');
  const panel = shipEditorPanel();
  if (panel) {
    panel.querySelector('[data-act="left"]').disabled = ship.size <= 1;
    panel.querySelector('[data-act="right"]').disabled = ship.size <= 1;
  }
  positionEditorPanel();
  if (panel) {
    const first = panel.querySelector('button:not(:disabled)');
    if (first) first.focus({ preventScroll: true });
  }
  Sfx.play('click');
}

function closeShipEditor(restoreFocus) {
  const editor = shipEditorEl();
  if (editor) editor.hidden = true;
  const screen = $('#screen-place');
  if (screen) screen.classList.remove('is-ship-edit');
  boards.place.classList.remove('is-editing');
  $$('#board-place .cell').forEach((cell) => cell.classList.remove('ship-selected'));
  if (state.placement) state.placement.editor = null;
  if (restoreFocus !== false) {
    try { boards.place.focus({ preventScroll: true }); } catch (e) { /* ignore */ }
  }
}

function rotateSelectedShip(dir) {
  const ed = state.placement && state.placement.editor;
  if (!ed) return;
  const r = Engine.rotateShip(state.playerBoard, ed.shipId, dir);
  if (!r.ok) {
    const panel = shipEditorPanel();
    if (panel) {
      panel.classList.add('is-shake');
      setTimeout(() => panel.classList.remove('is-shake'), 320);
    }
    const live = $('#ship-editor-live');
    if (live) live.textContent = 'Здесь не помещается. Поверни иначе или удали корабль.';
    toast('Здесь не помещается 😅', 'error');
    Sfx.play('error');
    return;
  }
  paintBoard(boards.place, state.playerBoard, true);
  $('#ship-editor-live').textContent = 'Корабль повёрнут';
  positionEditorPanel();
  Sfx.play('place');
  try { if (navigator.vibrate) navigator.vibrate(8); } catch (e) { /* ignore */ }
}

function deleteSelectedShip() {
  const ed = state.placement && state.placement.editor;
  if (!ed) return;
  const ship = state.playerBoard.ships[ed.shipId];
  if (!ship) { closeShipEditor(); return; }
  const size = ship.size;
```

Классический IIFE. Требования:

- Волны: буфер шума 4 секунды, зацикленный через lowpass ~500 Гц и медленную LFO.
- Редкая высокая нота пентатоники раз в 12–20 секунд.
- Мастер-гейн музыки `0.18 * volume`, при `duck` — `0.04`.
- `init()` создаёт `AudioContext` лениво, возвращает `false` при отсутствии API.
- `start()` без контекста возвращает `false`; с контекстом запускает планировщик и `true`.
- `stop()` останавливает таймер, глушит мастер-гейн, но не уничтожает контекст.
- `pause()`/`resume()` вызывают `ctx.suspend()/resume()`.
- `setEnabled(false)` останавливает; `setEnabled(true)` не запускает сам, только запоминает.
