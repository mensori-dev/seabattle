## Ограничения проекта

- Никаких ES-модулей в браузерных скриптах: только классические IIFE.
- Корень должен открываться через `file://`.
- Не менять ключ `seabattle.profile.v2` без миграции.
- Платформенные хуки — через `window.GamePlatform || window.YandexGame`; без SDK игра обязана работать.
- GamePush-сборка вырезает PWA, онлайн и внешние шрифты.
- После правок `js/*`, `index.html`, `style.css` поднимать `sb-vNN` в `sw.js` и `js/app.js`.
- Тесты: `npm.cmd test`; онлайн-смоук: `npm.cmd run test:online` (нужен `npm.cmd run server`).
- Пуш, деплой и релиз — только после подтверждения пользователя.
- Не коммитить `node_modules`, логи, временные файлы, `gamepush.config.json`.
