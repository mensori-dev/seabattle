## Описание (900–1200 символов)

```
Упакую вашу HTML5-игру в APK и AAB для RuStore и соберу отдельную версию для Яндекс Игр. Проверю, что проект запускается без интернета и внешних ссылок, исправлю типичные ошибки мобильной вёрстки и подготовлю файлы, которые принимают магазины.

Что входит:
— обёртка игры в нативное приложение и запуск на Android;
— иконки, сплэш-экраны и название под требования площадок;
— подпись release-сборки и проверка установки на телефоне;
— APK для RuStore и AAB для Google Play при необходимости;
— версия для Яндекс Игр с учётом ограничений платформы;
— политика конфиденциальности и базовые лицензии, если нужны;
— инструкция по публикации и передача всех файлов.

Отдельно проверяю касания и ориентацию экрана, паузу при сворачивании, сохранение прогресса, рекламные SDK и отсутствие запрещённых внешних запросов. Если игра уже опубликована, помогу с обновлением и выпуском новой версии.

Работаю с Capacitor и лёгкой WebView-обёрткой, без переписывания игры. Исходники остаются у вас, сборка воспроизводима.

В портфолио — «Морской бой — Морская арена»: довёл игру до PWA, APK и IPA, прошёл модерацию RuStore и подготовил сборку для Яндекс Игр.

Пришлите архив — проверю проект и назову точный срок.
```
