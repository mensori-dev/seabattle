# Авито: два объявления

Правила площадки: без ссылок и телефонов в тексте (модерация снимает), без слов «дёшево/акция/лучший»,
одно объявление = одна услуга, фото обязательно. Портфолио отправлять в переписке после первого сообщения.

**Город:** Йошкар-Ола, работа удалённо по всей России

**Заголовок (38 симв.):**
```
Доработка сайта: правки вёрстки и адаптив

```

## Порядок публикации

1. Авито → «Разместить объявление» → выбрать категорию из шапки выше.
2. Вставить заголовок и описание, поставить цену.
3. Загрузить фото (первое — самое понятное: скриншот сайта / экран компьютера).
4. Указать город и район, способ связи — сообщения Авито + телефон (телефон скрыт до отклика).
5. Опубликовать. Первое объявление проходит проверку 15–60 минут.
6. В настройках профиля включить уведомления в приложении — отвечать нужно в первые 10 минут, тогда объявление выше в выдаче.

## Что делать с первым сообщением

Шаблон ответа:
```
Здравствуйте! Спасибо за обращение. Чтобы назвать точную цену, задам три вопроса:
1) что нужно сделать (кратко);
2) есть ли пример сайта, который нравится;
3) когда нужно закончить.
Примеры работ пришлю сразу после ответа.
```

## Чего не делать

- не размещать два одинаковых объявления (бан за дубль);
- не вставлять ссылки и телефоны в текст описания;
- не писать «дёшево», «акция», «гарантия 100%» — модерация отклоняет;
- не соглашаться на предоплату «за материалы» от незнакомых — только оплата по факту или через Авито Доставку/безопасную сделку.
